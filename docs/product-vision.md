# Vision Spotlight

Une machine opérationnelle pour les pièces uniques sourcées notamment en Tunisie : achat → inventaire → identification → benchmark marché → prix → Studio → listing → validation → commerce → vente → retrait des autres annonces → marges.

L'ERP rend le travail délégable à des opérateurs; l'administrateur contrôle les validations, marges et accès. La boutique construit une clientèle indépendante. Shopify conserve checkout, paiements et commandes; aucune caisse maison. Vinted/Vestiaire sont des canaux manuels assistés, jamais présentés comme synchronisés en temps réel.
